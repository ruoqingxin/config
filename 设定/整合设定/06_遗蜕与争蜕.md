# 遗蜕与争蜕

## 遗蜕定义

遗蜕是一件普通物品与一丝大道法则碎屑的结合。忆境中的某件物品曾被至强散逸的道韵擦过，因而沾上法则气息。

遗藏稳定化后，遗蜕会在现实对应坐标附近以可触碰、可破坏的实体投影出现。下表时间是公开争夺与定锚窗口，不是自用后的总寿命：

| 来源品级 | 争夺窗口 |
| --- | --- |
| 凡忆 | 3天 |
| 玄章 | 7天 |
| 地书 | 15天 |
| 天图 | 1个月 |
| 道藏 | 数月以上 |

## 法则沾染强度

| 品级 | 沾染程度 | 物品特性上限 | 碎片价值 |
| --- | --- | --- | --- |
| 凡忆·薄 | 表面沾染，如落灰 | 极微弱 | 极少 |
| 凡忆·普通 | 略有渗透 | 微弱 | 少量 |
| 凡忆·厚 | 表层渗透 | 明显 | 少量以上 |
| 玄章 | 渗透内部 | 较强 | 中等 |
| 地书 | 法则与物品基本融合 | 强 | 大量 |
| 天图 | 物品成为法则载体 | 极强 | 丰沛 |
| 道藏 | 本源碎片凝成外壳 | 承载大道本身 | 核心级 |

示例：同一把刀从凡忆·薄的“比普通刀稍利”，可逐步上升到凡忆·厚的“挥刀无声”、玄章的“短暂消失半息”、地书的“自动偏转形成必中”、天图的“随意念换手”。

## 三种去向

| 选择 | 获益者 | 结果 |
| --- | --- | --- |
| 自用 | 定锚者 | 投影转为稳定实体，获得神奇效果；碎片随使用逐渐消耗 |
| 交易 | 至强代理人或相关势力 | 换取资源、功法、情报和关系 |
| 交还 | 至强或天道 | 碎片归位，补全大道或世界 |

自用定锚后仍可转交，但每次改换道韵归属都会损耗碎片，且已消耗的部分不能恢复。提炼或释放完碎片后，物品会变回普通凡物；在争夺窗口内整件交付损耗最低、收益通常最高，但持有者彻底失去控制权。

只有天道和至强能真正提炼法则碎片，普通修士只能引导释放或转移交付。

### 源头

遗藏稳定化 → 天道先回收三成用于维持忆境与世界 → 余下七成道韵封存于物品投影 → 遗蜕在现实坐标具现。

### 流向

遗蜕最终流向三个方向：修士定锚自用、至强代理人或宗门接收、逾期后由天道自然回收。三种流向之间存在取舍竞争。

### 层级结构

大势力处理遗蜕有明确的层级分工，低阶执事负责日常收储，高阶修士只在特定条件下介入。筑基期执事用定道石、骨针、余烬灯等工具完成鉴伪定价，不需要高深修为。长老只在出现地书级以上遗蜕、执事遇到无法判断之物或出现值得关注的散修时出面。

## 交付方式

- 至强代理人移交：交给对应至强的后人或道脉，通过血脉、道印链接传递。
- 节点释放：把遗蜕放到对应至强的坐标，主动断开连接，使碎片流向对方。
- 天道自然回收：争夺窗口结束时仍未定锚或交付，投影立刻散逸，剩余碎片由天道回收。
- 天道强制抽成：稳定化时，天道已经自动抽取30%。

普通修士引导释放损耗10%至20%；林澈因双核灵魂，损耗不到一成。

## 清浊道的特殊性

林澈融合澄浊元君本源，能直接吸收清浊道法则碎片，其他大道的碎片不能吸收。这不是提炼，而是同源归位。

| 项目 | 规则 |
| --- | --- |
| 触发 | 魂印自动感知，右手印记发热 |
| 过程 | 触摸遗蜕，碎片流入魂印并融入元君本源，持续10至数十息，期间无法移动 |
| 显性效果 | 净化、污染能力更稳定，消耗更低，手背印记加深 |
| 隐性效果 | 解锁元君记忆；后期可更低损耗引导其他大道碎片 |
| 限制 | 有承载上限；吸收后冷却1至3天；品级过高可造成魂印裂痕；过程可被打断 |
| 代价 | 灵力临时抽空三成，神识昏沉半日 |

天道抽成仍然有效；林澈吸收的是天道抽取30%后的剩余部分。

## 稳定化后的具现流程

1. 恢复进度到达100%，魂印确认稳定化完成，并将遗蜕坐标推送给参与者。
2. 天地回响出现：凡忆只有极淡光柱；玄章为光柱加钟鸣；地书以上可令天地变色。
3. 遗蜕由虚影凝实，耗时1至2个时辰。期间不可移动，但能被破坏。
4. 遗藏内部的意识回响进入静默或完成最后动作，仅贡献排名前列者可见。
5. 凝实完成后进入公开争夺窗口。窗口结束前，持有者须以魂印定锚自用或完成交付；逾期未处理则遗蜕散逸回收。

## 锚点回响处理

| 品级 | 稳定化后的表现 |
| --- | --- |
| 凡忆 | 完成最后动作后静默，不再移动 |
| 玄章、地书 | 说出与执念对应的完整话语，化为微光融入灵性虚空 |
| 天图、道藏 | 至强人格投影与时代群像化为天道底色或回响合音 |

稳定化不是复活，也不是删除，而是执念完成后静默或升格。情感收束保持轻：少对话、少告别、少抒情，把叙事重心转向遗蜕的价值与现实争夺。

## 争蜕规则

- 遗蜕坐标经魂印向相应范围广播，附近修士都可感知；恢复参与者优先得到消息。
- 争夺者包括恢复参与者、附近散修与掠灵者、中州势力、至强代理人和域外势力。
- 遗蜕存在期间可被转移、抢夺、损坏或摧毁。
- 争夺窗口内，持有不等于最终归属；完成魂印定锚或正式交付后才算结算。
- 窗口结束时仍未结算，遗蜕投影散逸，剩余法则碎片由天道回收。
- 严重损坏可能导致品阶跌落；彻底摧毁则本次遗蜕永久消失，但不影响已稳定化遗藏的公共查阅。
