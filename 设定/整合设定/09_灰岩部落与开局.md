# 灰岩部落与开局

## 部落定位

灰岩部落位于东荒边缘缓冲带，距中州边界约三日脚程，是林澈在本界的开局舞台和第一个“家”。部落靠半枯灵田、狩猎和恢复低品遗藏维生，还需向溯光时尊势力的扫荡队缴纳人头税。

第三版早期曾写“约两百人”，随后同版的完整部落表修订为350至400人，按后文采用350至400人。

## 人口与战力

| 项目 | 数量或人物 |
| --- | --- |
| 总人口 | 约350至400人 |
| 修行者 | 约60至70人，不足两成 |
| 凡人青壮 | 约150人，负责耕种、狩猎、建造和运输 |
| 凡人老弱 | 约120人，负责后勤 |
| 最高战力 | 族长石厚，筑基中期，部落唯一 |
| 筑基初期 | 狩猎队长老柴、石厚叔父石岷 |
| 炼气后期 | 4至5人，包括石坚和猎队骨干 |
| 炼气中期 | 十余人，是年轻主力 |
| 炼气初期 | 数十人，包括开局林澈 |

突破一个小境界都是部落大事。筑基中期足以成为一方地方霸主。

林澈开局采用后版统一境界名“炼气初期”，灵力存量仅约两成一。部落收留他，是因为他体内有灵力反应，至少能当半个劳力。

## 内部矛盾

### 石坚

石坚二十五岁，炼气后期，是族长石厚之子和部落下一代领袖候选。石厚四十七岁，巅峰期预计最多再维持十年。若石坚十年内不能突破筑基中期，部落很可能被吞并。

因此在石坚看来，每一份给外人的资源都从部落未来身上割肉；林澈要么是探子，要么是累赘。这是现实利益冲突，不应写成单纯嫉妒。

### 凡人与修士

- 凡人耕作供养修士，修士冒险换取愿力和资源，双方共生但并不平等。
- 凡人会质疑石家垄断高品遗藏的探索权。
- 半开窍凡人进入凡忆同样可能死亡，却常因粮食压力不得不冒险。
- 修士地位更高，但灵力难以补充，也承担跌境、神魂受创和死亡风险。

旧版“凡忆死亡率三至五成”与第七版“通常被击杀只弹出”不完全一致。最终解释为：忆境内普通被击杀不会现实死亡；开局队伍的高死亡率来自神魂彻底溃散、现实环境袭击、污染和超时等复合风险，不把普通死亡撤离直接写成现实死亡。

## 部落常接入的遗藏

旧版称其为“常驻仙卡”，与新版“遗藏无实体、按坐标锁定”冲突。最终改为部落掌握并长期维护的遗藏坐标。

| 遗藏 | 品级 | 频率 | 定位 |
| --- | --- | --- | --- |
| 《老兵扎甲》 | 凡忆 | 旧版称每周2至3次；与凡忆5至7天标准周期冲突，最终按特殊厚度或多坐标轮换处理 | 新人训练与基础资源来源 |
| 《枯井医案》 | 凡忆 | 每月1至2次 | 需要识字和药性知识，产低阶药方 |
| 《断矛冢》 | 玄章 | 每季约1次 | 筑基带队，部落最高收益来源，曾发生变体事件 |

《老兵扎甲》的具体开法需在正式设计时二选一：单一坐标遵循5至7天周期，或部落掌握多个相似凡忆坐标。当前不把“每周2至3次”作为单坐标硬规则。

## 老瘸的旧事

老瘸本名陈三更，曾是部落最强拾忆者，修为筑基初期巅峰。十五年前《断矛冢》发生变体，他拼死把队友送出，神魂左腿坏死，修为跌至炼气中期。

他独居部落边缘，教新人识字、理解遗藏和整理情报。林澈身上的气息与十五年前变体中“不该出现的东西”相似；他帮助林澈，既因看见过去的自己，也因这份异常直觉。

## 开局状态

- 林澈在灰岩部落醒来，浑身有伤，蓝星记忆完整，本界经历空白。
- 他知道自己是穿越者，但不知道澄浊元君本源的存在。
- 梦中偶尔出现上古战场和模糊白衣人影。
- 第一章先交代生存状态、魂印和进入忆境的基本概念，不立即进入忆境。
- 第一篇章中，他被迫参与《老兵扎甲》，首次零收益撤离，之后通过多轮试探掌握规则并站稳脚跟。
