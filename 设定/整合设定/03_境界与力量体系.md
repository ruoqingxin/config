# 境界与力量体系

## 本土灵气道统

| 境界 | 核心变化与能力 | 时代定位 |
| --- | --- | --- |
| 炼气 | 丹田气海成形，灵气循经脉运转，完成蜕凡；以近战和基础术法为主，灵力少、续航短 | 底层修行者 |
| 筑基 | 灵气化液，筑成道基，奇经八脉贯通；可驾驭法器、低空飞行、布置简单阵法，灵力开始缓慢自循环 | 地方中坚 |
| 金丹 | 灵液压缩为本源金丹；可御空、操控多件法器；金丹不碎，肉身重创仍有复苏机会 | 高阶战力 |
| 元婴 | 金丹破茧孕育元婴，神魂与灵力合一；元婴可离体、进行实质神魂攻击；肉身毁灭后可遁逃或夺舍 | 当代正常上限 |
| 化神 | 元婴化为纯阳之神，可撬动局部法则并展开领域 | 只见于万道纪、黄金纪元的遗藏残影和域外高阶敌手 |
| 炼虚 | 道韵与虚空法则相融，身形可虚实切换、短距挪移 | 万道纪与黄金纪元的顶级战力 |
| 合道 | 大道烙印世界，言出法随；常态下仅一枚果位，寿元约十万年 | 中千世界一界至强 |
| 大乘 | 合道圆满，道印大成，体内自成小天地 | 十位至强中仅两三人触及 |
| 渡劫 | 大乘圆满后引动九重成仙劫，需要大千法则支撑 | 本界历史上无人成功 |
| 仙 | 超脱世界束缚，长生久视 | 全书终点线 |

### 境界细则

- 炼气分九层；其他大境界分初期、中期、后期。
- 同一大境界内主要提升灵力总量、神魂强度与操控精度，不产生新的生命层次质变。
- 高境界进入低品遗藏时会受忆境力量上限压制，只保留战斗经验与法则感悟。
- 末法时代灵力不会自然快速恢复。低阶修士平时极少真正释放术法，常用“干烧”练习：在掌心聚起灵力后再收回，以回收大半消耗。
- 写战斗时同时标明修为、剩余灵力和可执行的具体行动。灵力存量统一用“成”描述。
- 下品灵石有明确补充价值；炼气二层吸收一整颗，可补约六七成灵力。

### 前期器物与资源层级

| 层级 | 适用境界 | 定位 |
| --- | --- | --- |
| 凡器、凡物 | 凡人与炼气初期 | 不含稳定灵性，只承担生活、训练和备用用途 |
| 灵兵、灵具、灵蚕护具 | 炼气 | 由低阶灵材或简单灵纹制成，消耗少量灵力即可发挥强化效果 |
| 炼气级符箓、丹散 | 炼气 | 回气、疗伤、轻身、避水、破甲等一次性或短时资源 |
| 下品灵器、灵器胚、筑基级阵件 | 筑基 | 具有完整灵性结构，需要筑基灵力稳定驾驭；炼气修士通常只能有限激发 |
| 筑基级丹药与灵材 | 筑基 | 用于筑基修炼、护脉、炼器与阵法，也是前期高价值交易物 |

“青铁灵兵”是炼气级兵器的常见统称，不等于下品灵器；后者具备完整灵性核心，价值和驾驭门槛明显更高。

## 域外执妄道

执妄道以执念、纷争、恐惧和绝望为资粮，浊力天然侵蚀灵气。

| 执妄道 | 对应本土境界 | 主要能力 |
| --- | --- | --- |
| 染躯 | 炼气 | 以浊气改造血肉 |
| 聚妄 | 筑基 | 凝聚妄核，放大周围负面情绪 |
| 执丹 | 金丹 | 污染灵力与法器，通过收割执念恢复 |
| 阴婴 | 元婴 | 展开浊域，神魂开始彻底执念化 |
| 障神 | 化神 | 成为移动浊源，播撒长期潜伏的执念种子 |
| 堕虚 | 炼虚 | 浊化大片地域与遗藏 |
| 极妄 | 合道 | 冲击世界本源，放大一界纷争 |

修为越深，本我越淡。本界修士转修至阴婴后，魂印彻底失效。

环境对执妄道战力的影响：核心死寂区约增强一成；深度腐化区正常；缓冲带衰减半阶至一阶；中州下降一个大境界以上，且境界越高压制越明显。

## 两种探索路线

### 寻道者

主动进入忆境，恢复遗藏、积累愿力并获取稳定传承。难度高、成长慢，但上限高，是传火者与林澈的路线。

### 掠灵者

不恢复遗藏，强行抽取遗藏表层灵性。短期速成，却会磨灭执念、加深污染，最终令遗藏死寂。噬灵宗是代表势力。
