# 项目配置

源表位于 `Datas`，按战斗、技能、敌人、物品、装备、储物、地图七类拆分，另有注册表和数值枚举。装备六张专属子表维护在 `装备配置表.xlsx`，物品公有字段仍在 `物品配置表.xlsx`。

`物品配置表.xlsx`只保留`item`主表。药效`potion`和药品关联`potion_item`归战斗配置，修理补给`repair`归装备配置，探索体力补给`stamina`归地图配置，容器容量与承重`container`归储物配置。各子表仍独立维护，编号和跨表引用保持。

运行 `gen_client.bat`：Luban 导出 29 张运行表，打包并同步到相邻 `ItemChangeWorld` 客户端。需要 .NET 8；打包使用本目录的 Node。生成代码和数据不可手改。

配置数据行按固定 ID 数值升序排列，新增行插入对应编号位置，整行移动且不重编号。旧物品 `101–108` 已删除退役，现有武器从 `109` 开始，退役编号不得复用。

数字枚举表头用批注注明数字含义；数字 ID 右侧提供只读名称列，辅助列表头用 `##` 前缀、类型和分组留空，不参与导出。具体维护方式见现行第 09 号文档“配置设定规则”。

字段说明行统一中文，程序字段名及类型保持原名。批注使用黑字、浅黄色底和足够尺寸，必须在 WPS 或 Excel 中实际检查可读性。

现行开发规则见 `AGENTS.md` 及 `E:/NowChange/ItemChangeWorld/document/09_整合开发/README.md`。
