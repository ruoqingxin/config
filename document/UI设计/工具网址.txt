飘，如果你主要做 抠图、改字、切图、修图、游戏 UI，我建议这样搭配：

最推荐组合
1. Photopea：最像 PS，优先推荐
适合：改字、抠图、切图、修图、打开 PSD、临时改图

官网：
https://www.photopea.com

优点：

浏览器直接用，不用安装。
操作逻辑很像 Photoshop。
支持 PSD 文件，适合改别人给你的 PS 源文件。
适合做简单 UI、图标、按钮、海报、修图。
缺点：

免费版有广告。
大文件可能会卡。
复杂效果不如 Photoshop 稳。
如果你只想找一个最接近 PS 的免费工具，就用 Photopea。

2. GIMP：免费开源，适合修图和抠图
适合：修图、抠图、调色、改图、图片处理

官网：
https://www.gimp.org

GIMP 是官方定位的免费开源图像编辑器。它适合离线使用，功能比较全，适合做图像处理、修图、抠图、调色等。(gimp.org)

优点：

完全免费。
Windows / macOS / Linux 都能用。
适合修图、抠图、批量处理。
不需要联网。
缺点：

操作习惯和 PS 不太一样。
做游戏 UI 排版不如 Figma 方便。
3. Krita：适合画图、做游戏美术
适合：游戏角色、图标、技能图、道具图、场景、插画

官网：
https://krita.org/en/

Krita 是免费的开源绘画软件，官方定位就是专业绘画工具，适合概念图、插画、数字绘画等。(krita.org)

优点：

免费开源。
笔刷很强。
很适合画游戏图标、技能图、道具、角色立绘。
数位板支持不错。
缺点：

不太适合复杂 UI 排版。
修图、改字不如 Photopea 方便。
4. Figma：最适合做游戏 UI 界面
适合：游戏界面、按钮、弹窗、背包、商城、设置界面、登录界面

官网：
https://www.figma.com

Figma 官方定位是免费的在线 UI 设计工具，可用于创建、协作、原型和交付 UI 设计，并且能在浏览器中运行。(figma.com)

优点：

做 UI 布局非常方便。
适合按钮、面板、弹窗、图标排版。
可以做组件，方便复用。
浏览器就能用。
能导出 PNG、SVG 等素材。
缺点：

图片精修能力不如 Photopea / GIMP。
更偏 UI 设计，不是修图软件。
按你的用途直接选
需求	最适合工具
抠图	Photopea / GIMP
改图片里的字	Photopea
切图、导出 PNG	Figma / Photopea
修图、调色	GIMP / Photopea
做游戏 UI 界面	Figma
做按钮、弹窗、背包界面	Figma
画技能图标、道具、角色	Krita
打开 PSD 文件	Photopea
离线使用	GIMP / Krita
我的建议：你就装/用这三个
如果你是做游戏 UI，我建议：

Figma：做游戏界面排版、按钮、弹窗、背包、商城页面。
Photopea：打开 PSD、改字、抠图、简单修图。
Krita：画图标、道具、技能、角色、纹理。
这三个基本可以覆盖你说的全部需求。

最简单方案
如果你懒得折腾：

在线改图、改字、抠图：Photopea
做游戏 UI：Figma
画游戏素材：Krita
优先顺序：
Photopea > Figma > Krita > GIMP

如果你电脑配置一般，先别装太多，直接用 Photopea + Figma 就够了。
